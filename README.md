This system was developed as a coursework assignment for the **Computational Thinking** course by **Group N9 - Class 24TNT1**.

**Live Demo:** [https://edusparkai-theta.vercel.app/](https://edusparkai-theta.vercel.app/)

**Slides:** [https://docs.google.com/presentation/d/1oJCMx6LQ8JWYGSMjlHvt3za9YmcifYwNisiu6C9r_Xc/edit?usp=sharing](https://docs.google.com/presentation/d/1oJCMx6LQ8JWYGSMjlHvt3za9YmcifYwNisiu6C9r_Xc/edit?usp=sharing)

EduSpark.AI is an intelligent, RAG-powered study assistant designed specifically for primary school students. The system provides interactive, accurate, and age-appropriate learning support across three core subjects: Mathematics, Vietnamese, and English.

Navigating early education can be challenging for both young learners and their parents. Often, students need immediate, easy-to-understand explanations when doing homework, while parents may not always have the time or pedagogical methods to guide them effectively. EduSpark.AI bridges this gap by acting as a reliable, 24/7 virtual tutor.

Here is why EduSpark.AI stands out:
* **Targeted Knowledge Base:** By leveraging Retrieval-Augmented Generation (RAG), the system ensures that all answers are grounded in verified educational materials, significantly reducing AI hallucinations and providing trustworthy academic assistance.
* **Age-Appropriate Interaction:** The communication style is tailored to primary school students, making complex concepts simple, engaging, and easy to grasp.
* **Modern Architecture:** Built with a robust stack including React, FastAPI, and advanced LLMs to ensure a seamless, high-performance experience for the end-users.

# Getting Started

<!-- This is an example of how you may give instructions on setting up your project locally.
To get a local copy up and running follow these simple example steps.
 -->

This section provides comprehensive instructions on how to set up the EduSpark.AI project on your local machine for development and testing purposes.

The system architecture is decoupled into a frontend application (built with React and Vite), a backend API (built with FastAPI and Python), and a PostgreSQL database. To ensure consistency across different development environments and to eliminate the complexity of configuring local databases, we utilize Docker to containerize and manage the backend services.

## Prerequisites

<!-- This is an example of how to list things you need to use the software and how to install them.
* npm
  ```sh
  npm install npm@latest -g
  ``` -->


Ensure your system meets the following requirements and has the necessary software installed before proceeding:
* **Git**: Required to clone the repository and manage version control.
* **Node.js & npm**: Essential for installing dependencies and running the React frontend. We recommend using the LTS (Long Term Support) version of Node.js.
  ```sh
  npm install npm@latest -g
  ```
* **Docker Desktop**: Required to orchestrate the FastAPI backend and PostgreSQL database containers. Download and install the appropriate architecture version (typically x86_64 for standard Windows) from Docker's official installation guide.
* **Google AI Studio Account**: Since the core functionality relies on Retrieval-Augmented Generation (RAG), you will need an active account to generate a Gemini API Key for the language model integrations.
* **Cloudflare Account**: Required to obtain a Cloudflare API Token and Account ID for backend AI/storage services.


## Installation

Follow these steps sequentially to establish your local development environment.

1. **Obtain Required API Keys**
* Navigate to [Google AI Studio](https://aistudio.google.com/) and create a free API Key. 
* Log in to your [Cloudflare Dashboard](https://dash.cloudflare.com/). Go to **My Profile > API Tokens**, click **Create Token**, and generate a token with the required permissions (e.g., Workers AI or R2). Copy the token, and also grab your **Account ID** from the dashboard home page.
2. **Clone the repo**
   ```sh
   git clone https://github.com/NHuy165/Group-project---Study-assistant.git
   cd Group-project---Study-assistant
   ```
3. **Configure Backend Environment Variables**
* Navigate to the directory containing the backend services.
* Locate the `.env.example` file. Duplicate this file and rename the copy to `.env`.
* Open the newly created `.env` file and insert your Gemini API Key alongside any database credentials required by the PostgreSQL container:

   ```sh
   # Replace with your actual key
   GEMINI_API_KEY=your_gemini_api_key_here
   CLOUDFLARE_API_TOKEN=your_cloudflare_api_token_here
   CLOUDFLARE_ACCOUNT_ID=your_cloudflare_account_id_here
   ```
4. **Configure Frontend Environment Variables**
* Navigate to the `frontend` directory.
* Create a new file named `.env` and define the local API endpoint routing:

   ```sh
   VITE_API_URL=http://localhost:8000/api
   ```
5. **Build and Initialize Backend Services (Docker)**
* Execute the following command to build the Docker images and spin up the containers. This command must be used during the initial setup or whenever dependencies in `requirements.txt` are updated:
   ```sh
   docker compose up --build
   ```
* Note: For all subsequent local development sessions, you can omit the build flag and simply run `docker compose up`.
* The backend API and PostgreSQL database are now actively running in isolated containers. You can verify this by accessing the interactive FastAPI documentation (Swagger UI) at: http://localhost:8000/docs

6. **Initialize the Frontend Application**
* Open a secondary terminal window and ensure you are routed inside the `frontend` folder.
* Install all necessary Node packages defined in `package.json`:
    ```sh
    npm install
    ```
* Boot up the Vite development server:
    ```sh
    npm run dev
    ```
